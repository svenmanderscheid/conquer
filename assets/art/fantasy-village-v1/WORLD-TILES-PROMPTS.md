# Four modular meadow variants

Generated with built-in Imagegen, four separate calls. Input style reference: world-terrain-v3-fewer-trees.png. Output files: world-tile-0.png through world-tile-3.png in this directory. A/B open grass, C small rocks, D one tree. Original PNGs retained. Runtime caches each at 768 square pixels, blends 128-pixel leading edges with smoothstep ramps and selects by signed coordinate hash, without rotation/reflection. These source images are not claimed to have pixel-matched edges; continuity is supplied by overlap blending in the preview. No production map or coordinates changed.
