# Kartenillustrationen

Die acht SVG-Dateien wurden am 10. September 2026 für Conquer als eigene Vektorgrafiken erstellt: Burg, Siedlung, Getreidehof, Holzfällerlager, Steinbruch, Goldmine, Kristallader und Marschtrupp. Sie werden im Atlas auf einem deterministisch gezeichneten Gelände verwendet.

Monster verwenden weiterhin die vorhandenen lokalen Illustrationen. Alle auswählbaren Orte und Marschrouten kommen aus dem tatsächlichen Spielstand; gezeichnete Bäume, Hügel, Flüsse und Wege dienen der Landschaftsgestaltung.
