## Note for Conquer

This sprite set is used as a temporary placeholder during early Conquer
development. The intent is to replace these tiles with Conquer-native
pixel art (in the `pixel/` sprite set) before public launch. Until then,
these tiles allow the rendering system to be developed and tested with
real visual content rather than placeholder rectangles.
